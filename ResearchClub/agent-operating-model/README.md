# AI Agent Operating Models for Software Development

Research on how individuals and engineering organizations are using AI to build
software, when a single agent is preferable to multiple agents, how multi-agent work
should be coordinated, and whether permanent roles still make sense as general-purpose
models improve.

## Contents

- [`single-vs-multi-agent-research.md`](./single-vs-multi-agent-research.md) — the full
  evidence review, decision framework, recommended operating model, AgentWeave
  implications, delegation contract, and measurement plan.

## One-line conclusion

Use **one accountable primary agent with reusable skills as the default**, and add
temporary workers only for independently verifiable, context-isolating, or genuinely
parallel work. Define workers by their task, boundary, tools, and output contract—not
by theatrical software-company roles.
